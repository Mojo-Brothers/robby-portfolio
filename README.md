## 🛠️ Architecture & Technical Stack

* **Frontend:** React 19, TypeScript (Strict Mode), Vite 6, Tailwind CSS v4, Lucide React
* **Routing:** React Router v7 with route-level code splitting (`React.lazy` & `Suspense`)
* **Design System:** *"Clinical Precision Meets Modern Enterprise"* (Slate Canvas, Precision Teal Accents, Zero Neon Fluff)
* **Data Model:** Static Typed Single Source of Truth (`src/data/projects.data.ts`) with zero runtime database overhead
* **Accessibility:** WCAG 2.1 AA compliant (semantic HTML, keyboard navigation, visible focus rings, reduced motion support)
* **SEO:** Open Graph tags, canonical URLs, dynamic meta tags, JSON-LD Schema.org `Person`, `robots.txt`, and `sitemap.xml`

## 💻 Local Development

### Prerequisites
* Node.js `>= 20.x`
* npm `>= 10.x`

### Installation & Execution
```bash
# 1. Clone repository
git clone https://github.com/Mojo-Brothers/robby-portfolio.git
cd robby-portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build & Typecheck
```bash
# Type check and build optimized bundle
npm run build

# Preview production build locally
npm run preview
```
